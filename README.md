## 🎯 Course Objective

The course aims to provide an understanding of analyzing algorithms and their complexity. It also focuses on developing data structures, including Abstract Data Types (ADTs), Linked Lists, Stacks, Queues, Trees, and Graphs using the C++ programming language.

Additionally, the course introduces mathematical techniques for analyzing the efficiency of algorithms and common operations performed on different data structures. Students also implement algorithms and conduct real-system performance measurements and analyses using C++.

This course contributes to the attainment of **SDG 9 – Industry, Innovation, and Infrastructure**.

**I. Course Introduction**

- T.I.P. Graduate Attributes and Institutional Learning Outcomes
- Program Educational Objectives and Student Outcomes
- Course Syllabus and Course Requirements
- Orientation for Industry and Laboratory Software and Tools

**II. Introduction to Data Structures and Algorithm Analysis**
- C++ Programming Review
- Abstract Data Types (ADTs)
- Space and Time Complexity
- Algorithm Analysis Techniques

**III. Arrays and Linked Lists**
- Dynamic Memory Allocation
- Singly, Doubly, and Circular Linked Lists

**IV. Stacks**
- Stack Using Arrays
- Stack Using Linked Lists
- Implementation in C++
- Problem Solving

### 📗 Midterm Period

**I. Queues**
- Queues Using Arrays
- Queues Using Linked Lists
- Implementation in C++
- Problem Solving

**II. Searching Techniques**
- Linear Search
- Binary Search
- Hashing

**III. Sorting Algorithms**
- Basic Sorting Algorithms

### 📙 Final Period

**I. Tree ADT**
- General Trees and Binary Search Trees
- AVL Trees
- Tree Traversal Algorithms
- Solving Problems Using Trees

**II. Graph ADT**
- Adjacency Matrix and Adjacency List
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Solving Problems Using Graphs

**III. Basic Algorithm Analysis**
- Theoretical and Experimental Methods in Measuring Time
- Time Complexity Classes
